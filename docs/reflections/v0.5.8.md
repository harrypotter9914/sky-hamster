# 0.5.8 | Fall away from a platform, not through it

# 0.5.8：掉落应该离开平台，而不是穿过它

Rolling off an edge looked like passing through the ground. I requested this fixed and installed in the class version before full-game sound and title work continued.

我发现小球滚出边缘时，看起来会从地面里面穿下去。我要求先修这个问题并装到课堂版，再继续完整版的声音和开始界面。

The failure state froze world coordinates and only shifted the ball image downward, losing lateral inertia. That contradicted rolling off and made the platform look like a membrane.

检查后发现，原来的失败状态停住了世界坐标，只把球的屏幕图像向下移，横向惯性消失了。这和我想要的滚落不一致，也让平台边缘看起来像一层膜。

Falling now uses spatial motion: retain horizontal exit velocity, apply gravity to height, and retain sidewall contact. The camera stays at the edge so players see an outward fall rather than following it downward.

我将掉落改成实际的空间运动：保留离开边缘时的水平速度，重力改变高度，平台侧面仍然能挡住球。相机留在边缘，让玩家看清它是向外掉下去，而不是跟着下坠。

Checks covered all four edges, decreasing height, inertia, one failure count, and automatic retry. Simulator visuals and four-direction hardware checks passed. The class build keeps its simple flow without music or new menus.

我分别验证了四个方向的边缘、高度下降、惯性保留、失败只计一次和自动重试。模拟器画面检查和真机四向检查都通过。课堂版保留原有简洁流程，不在这次修复里加入音乐或新的菜单。
