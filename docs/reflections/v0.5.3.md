# 0.5.3｜选关应该一列一列地读

The old order read 1/2 across, then jumped back left for 3/4. I preferred 1/2/3 down the left, then 4/5/6 down the right.

我觉得原来的选关顺序有点迷糊：先横着看 1、2，再跳回左边看 3、4。我更希望左边一列直接是 1、2、3，右边一列接着是 4、5、6。

Each page should keep that order. This adjusts layout and D-pad navigation to match reading, without new gameplay.

这样我看完一列再看下一列，下一页也保持一样的顺序。这次只调整选关的排列与方向键移动，让阅读顺序和操作对应，不增加新的玩法。
