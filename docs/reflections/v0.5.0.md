# 0.5｜我想让控球开始面对会变化的路线

## 我为什么继续增加关卡

前几关已经能练习推进、坡道和跳跃，但我还想用更多路线试各种跳跃情况。我不希望只在一个缺口上验证跳跃就结束，还想看看连续起跳、落地后重新准备，以及把已有操作组合起来，会是什么感觉。

## 我想让玩家判断时机

我这次想加入会移动的板子和旋转的地面。它们不是由玩家随时控制的机关，而是自己运动。玩家要观察它们的节奏，找到合适的时机冲过去。

我考虑的场景不止一种：有的路被挡板拦住，要等开口；有的地面有洞，走错时机会掉下去；还有的需要先上到移动的东西上，再跟着它去另一边。我希望这些变化仍然围绕控球，而不是另做一套操作。

## 我特别想尝试旋转接驳

我想要一种体验：先滚上旋转的地板，等它把球转到另一面，然后及时滚走。这样玩家不只是判断什么时候进场，还要判断什么时候离开。

这个过程会用到之前练习的力度控制。上板时不能一味加速，上去以后也需要控制自己不掉下去，到出口时再决定怎样离开。我想看看这种“上去、等待、离开”的节奏是否有意思。

## 我为什么还要综合长关

只做单项测试还不够。我想把此前出现过的坡道、跳跃、转弯和新机关组合到同一条更长的路线里，看看能不能形成一个完整流程。

所以这次先用独立关介绍不同机关，再做综合路线。它们目前仍然是用来体验和调整的原型关卡；机关速度、等待窗口和路线长度是否合适，还需要实际操作后判断。
