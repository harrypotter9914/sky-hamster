# 0.6：把声音和完整流程留给完整版

## 我先处理课堂需要的问题

我提出增加声音和开始画面时，也发现了边缘掉落穿模。我要求先修掉落并装到课堂版。0.5.8 先完成四向检查和真机部署，然后才继续这些新功能，这样课堂试玩不被后续内容打乱。

## 我希望声音解释正在发生什么

我最先想到的是滚动、跳跃、掉落和撞墙，也考虑了背景音乐。我不需要单独的加速音效。最终加入落地、检查点、终点、菜单确认和轻微的蓄跳刻度提示，让反馈对应实际事件。

滚动声只在轨道上移动时出现，随速度变化；腾空、停止或进入菜单时停止。撞墙声需要足够明显的碰撞，并有最小播放间隔，避免贴墙时一直响。检查点只在首次到达时提示。

## 我先采用一套统一的轻量声音

我了解了 Kenney 和 Freesound 这些素材选项，但这一版先用可重新生成的合成音色。音乐放得很轻，音效与音乐分别开关。我不希望声音遮住操作感，也不希望为它重新引入运行卡顿，因此使用提前生成的采样，而不是每帧合成声音。

## 我把开始画面和教学分开

我不想再直接把玩法介绍当成开始画面，所以新增了带悬浮轨道和小球图案的标题菜单：进入游戏、选关、音效和音乐开关。玩法介绍仍在进入对应关卡时出现。系统菜单可以返回标题和声音设置。

完整版掉落后新增明确的失败重试界面，显示失败次数并说明检查点是否保留。A 重试，B 选关。课堂版依然快速自动重试，不增加这些流程。

## 我验证了什么

我检查了开始和失败界面的实际显示，并测试菜单切换、起跳和撞墙声音触发、撞墙冷却、失败重试和课堂模式关闭新增功能。随后用开启声音的真机构建跑持续输入测试，性能结果和限制保存在本版说明中。声音的最终音量与舒适度仍可根据实际试玩反馈调整。
