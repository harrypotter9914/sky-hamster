# v0.6.5 — 只包含滚动的合成声音

根据实际试听反馈，0.6.4 的录音片段带有不需要的落地感和较大的碰撞声，不适合持续滚动。本版不再截取录音，重新合成 4 秒循环：小接触激发短衰减、非整数倍频率共鸣，避免持续噪声底、低频嘟声和长时间铃声。声音不包含玻璃珠落地的单独过程。

球速控制采样播放速率和音量：慢速轻且稀疏，快速更密集。音高也随播放速率变化。静止、腾空、暂停时仍停止滚动；其他效果和音乐不变。课堂版保持原样。

验证：采样 22050 Hz、16-bit、单声道，峰值 0.300；主机 Lua 检查及 SDK 构建通过。电脑检测到 COM5 USB 串行设备处于错误状态，没有可用串口，本次尚未安装或真机试听。合成音色仍需主观试听确认。
