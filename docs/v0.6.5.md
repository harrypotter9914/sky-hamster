# v0.6.5 — Synthesized rolling only

# v0.6.5 — 只包含滚动的合成声音

Listening found unwanted drop/impact character in 0.6.4. A new four-second synthesis uses small contacts and short inharmonic resonances, without noise beds, bass beeps, long ringing, or the initial drop.

根据实际试听反馈，0.6.4 的录音片段带有不需要的落地感和较大的碰撞声，不适合持续滚动。本版不再截取录音，重新合成 4 秒循环：小接触激发短衰减、非整数倍频率共鸣，避免持续噪声底、低频嘟声和长时间铃声。声音不包含玻璃珠落地的单独过程。

Speed controls playback rate/volume: slow light/sparse, fast denser, with pitch following rate. Still/airborne/pause stops it; other effects/music/class stay.

球速控制采样播放速率和音量：慢速轻且稀疏，快速更密集。音高也随播放速率变化。静止、腾空、暂停时仍停止滚动；其他效果和音乐不变。课堂版保持原样。

22050 Hz/16-bit mono peak 0.300, Lua and SDK passed. COM5 had an error and no usable serial port, leaving installation/listening pending; timbre requires subjective confirmation.

验证：采样 22050 Hz、16-bit、单声道，峰值 0.300；主机 Lua 检查及 SDK 构建通过。电脑检测到 COM5 USB 串行设备处于错误状态，没有可用串口，本次尚未安装或真机试听。合成音色仍需主观试听确认。

Later COM4 reconnection installed/launched 0.6.5. Three startup PASS groups covered slopes/control, machinery/checkpoints, and depth/edges. It is ready to hear; feedback remains pending.

后续连接复测：真机恢复为 COM4，0.6.5 安装完成并已启动。串口返回三组启动 PASS，覆盖坡道与控制、机关与检查点、遮挡与平台边缘。现在可在真机试听；听感仍等待实际反馈。
