# v0.5.1 — Match barrier form and collision

# v0.5.1 — 挡板外观与碰撞一致

Timed/moving barriers are complete boxes with sides, ends, and top, using collision height visually. Misleading floor-like crossing lines are removed. Opening, pushing, and layouts stay.

定时挡板与移动推板改为完整长方体：两侧、端面和顶面一并绘制，显示高度使用碰撞所用的高度。移除原来容易被误读为可踩路面的挡板底面交叉线。开门状态、推动逻辑和关卡布局不变。

SDK/Lua 5.4 regressions passed. Simulator closed; pdutil found COM4, copied/ejected safely, and sent run. Hardware appearance/feel remained unconfirmed.

验证：SDK 编译和 Lua 5.4 回归检查通过。已关闭模拟器；pdutil 检测到 COM4，完成真机文件复制与安全弹出，并发送运行命令。尚未确认真机上的实际画面和操作手感。
