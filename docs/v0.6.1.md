# v0.6.1 — 点位标签与选关返回

- START、CHECK/SAVED、FINISH 的地面标记与悬浮标签分层：地面标记先画，球居中，标签、连接线与旗帜后画。小球不会盖住悬浮标签。
- 根据静态赛道选择较空旷的一侧放置标签，使用连接线指向触发点；方向在准备关卡时缓存，不随小球位置反复跳动。标签限制在游戏区域内。
- 从标题菜单或标题上的系统菜单进入选关，B 返回标题并保留标题菜单选项。
- 从游戏进入选关，B 恢复进入前的关卡、球位置、速度、跳跃、检查点、力度及时间；不重新加载关卡。
- 从教学或暂停地图进入则返回对应界面。选关中再次打开选关不会覆盖原始返回位置。A 确认才会加载选中的关卡。

验证：主机回归覆盖两种标题入口、游戏内非首关返回、状态保留、重复打开选关、教学与地图返回，以及球先画、SAVED 标签后画的顺序。完整既有回归通过。模拟器实际检查检查点标签移至赛道外侧。完整与课堂配置编译通过；真机课堂包继续保留已部署的 0.5.8。
