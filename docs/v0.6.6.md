# v0.6.6 — Sparse, light slow rolling

# v0.6.6 — 稀疏、轻微的低速滚动声

Feedback called slow sound too dense/strong, like alien speech. Spacing changes 10–20 → 105–165 ms; decay 4.5 → 1.2 ms; pitch range ±8% → ±2%; peak 0.30 → 0.20, with lower slow gain. Speed-rate behavior, other mechanics, and class stay.

低速试听被反馈为过密、过强，像外星人说话。基础接触间隔从 10–20 ms 改为 105–165 ms，主共鸣衰减从 4.5 ms 缩短至 1.2 ms，随机音高范围从 ±8% 缩小至 ±2%。采样峰值从 0.30 降到 0.20，低速音量同步下调。保留随球速变化的播放速率，不改变其他游戏机制。课堂版不变。

PCM peaks and SDK passed; installed/launched on hardware, awaiting listening feedback.

验证：PCM 峰值检查和 SDK 构建通过，已安装并启动到真机。音色等待真机试听反馈。
