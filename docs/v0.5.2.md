# v0.5.2 — Occlusion and sidewalls

# v0.5.2 — 遮挡与平台侧壁

- Projected object volume determines visible ball regions, preserving exposed parts instead of showing the entire ball through barriers.

- 按投影与物体体积计算球的局部可见区域，保留露出来的部分；挡板后方不再全身穿透显示。

- Platform tops/sides occlude the ball; shadows/charge lines draw before barriers.

- 平台台面与侧壁也参与球的遮挡；影子和蓄力线先于挡板绘制。

- Low jumps hit sides, slightly rebound, and fall; fully below the platform bottom avoids invisible-wall contact.

- 低于平台台面的跳跃会撞到侧壁、轻微回弹并继续下落；完全低于平台底部时不被隐形墙拦住。

- High-enough jumps still land normally; no new input rule.

- 足够高的跳跃仍可正常跨边落地，未新增操作规则。

Lua 5.4 updates/depth/landing regressions and SDK build passed. Simulator views confirmed hidden rear balls and visible front balls. Hardware installed and received run, but no manual completion/FPS measurement was performed.

验证：Lua 5.4 回归检查（14 关更新流程、前后遮挡、撞边与正常落地）；SDK 编译；模拟器定点确认挡板后球被遮住、前方球正常显示。已向连接的 Playdate 安装并发送运行命令；未完成真机人工通关或帧率测量。
