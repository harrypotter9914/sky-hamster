# v0.5.5 — Classroom core test

# v0.5.5 — 课堂核心试玩版

A separate configuration retains the full 14-course game and supplies **Sky Hamster Core Test / 0.5.5-core** for September 10.

新增独立构建配置，保留完整 14 关版本，同时提供 **Sky Hamster Core Test / 0.5.5-core**，用于 9 月 10 日的核心测试。

- Main test: short flat turning road for clockwise force, direction, inertia, fall/retry.

- 主测试：一条短平地转弯路线，验证顺摇推进、方向选择、惯性与掉落重试。

- Optional: zero-force descent and gravity/propulsion understanding.

- 可选测试：零推进下坡，观察对重力和推进关系的理解。

- No jump/charge prompts, moving machinery, or long combinations.

- 无跳跃、蓄跳提示、移动机关或综合长关。

- Retains 0.5.4 optimization with separate name/bundleID; full game unaffected.

- 保留 0.5.4 的性能修复。独立名称和 bundleID，正式完整版不受影响。

Set PLAYDATE_SDK_PATH and run `./build.ps1 -Classroom`; no argument builds full. Source still defaults to full mode.

构建：设置 PLAYDATE_SDK_PATH 后运行 `./build.ps1 -Classroom`。不加参数则构建完整版本。源代码默认仍为完整模式。

Checks cover all 14 courses, classroom propulsion/disabled jumping/two goals, and both SDK builds. Classroom installed and received launch; first real player testing awaited class.

验证：完整 14 关回归、课堂模式的推进、禁用跳跃及两个终点检查、两种配置 SDK 编译。课堂版已安装并发送真机启动命令；首次真实玩家测试尚待课堂进行。

See [test plan](classroom-playtest.md) and [reflection](reflections/v0.5.5.md).

详见 [试玩计划](classroom-playtest.md) 和 [设计思考](reflections/v0.5.5.md)。
