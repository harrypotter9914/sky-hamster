# v0.6.0 — Full-game audio and opening flow

# v0.6.0 — 完整版声音与开始流程

Classroom 0.5.8 edge fixes completed/deployed first. Hardware class remains 0.5.8 without these additions.

先完成并部署课堂 0.5.8 的边缘修复，再开展本版工作。课堂真机版本保持 0.5.8，不加入以下功能。

- Separate SKY HAMSTER title with play, selection, sound, and music; instruction stays separate.

- 独立 SKY HAMSTER 开始画面，包含进入游戏、选关、音效开关、音乐开关；教学与开始画面分开。

- Failure shows falls, checkpoint, A retry/B select; class still auto-retries.

- 失败后显示掉落次数、检查点提示和 A 重试 / B 选关。课堂配置仍自动重试。

- Nine sound types: rolling, jump, landing, fall, wall, charge tick, checkpoint, finish, menu.

- 九类音效：滚动、跳跃、落地、掉落、撞墙、蓄跳刻度、检查点、终点、菜单。

- Quiet 12-second music loop with separate toggle; no acceleration sound.

- 一段 12 秒低音量循环音乐，可独立关闭。没有单独的加速音效。

- Offline 22050 Hz mono samples total about 663 KiB, without external recordings. SDK players run without live synthesis/streaming.

- 音频离线合成为 22050 Hz 单声道采样，总约 663 KiB；无外部录音。运行时使用 SDK 原生播放器，不实时合成、不流式读盘。

- Classroom excludes audio/player initialization/title/failure panels.

- 课堂构建排除音频目录，不初始化播放器，也不展示标题和失败面板。

## Verification

## 验证

Host regressions cover 14-course updates, four-way falls, collision, jumps, selection, title, audio toggles, impact cooldown, jump sound, retry, and mode isolation. PCM peaks have no clipping. Simulator title/failure views and both SDK builds passed; class has no audio folder.

主机回归覆盖原有 14 关更新路径、四向掉落、碰撞、跳跃、选关，以及标题进入、音效/音乐切换、撞击冷却、起跳音效触发、失败重试和课堂功能隔离。生成音频逐个检查峰值，未发生 PCM 削波。模拟器实际检查标题菜单和失败面板。SDK 完整/课堂两种配置编译通过，课堂包不含 audio 目录。
