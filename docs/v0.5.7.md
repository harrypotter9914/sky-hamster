# v0.5.7 — Reduce temporary occlusion allocation

# v0.5.7 — 减少遮挡计算中的临时分配

- Reuse fixed vertices/workspaces and output polygons for clipping/hulls.

- 遮挡裁剪、凸包计算改用固定的顶点与工作缓冲区，游戏循环复用输出多边形。

- Conservatively cull distant machinery before constructing shapes; reuse unchanged poses/dimensions.

- 远处机关先通过保守投影范围剔除，再构建遮挡体；位置、角度和尺寸未变的机关复用已有数据。

- Use Playdate idle-frame collection to limit accumulation.

- Playdate 利用每帧空闲时间运行垃圾回收，减少垃圾积累。

- Preserve force, jump, collision, and 14 courses; build separate two-course class mode too.

- 玩法、力度、跳跃、碰撞和 14 关内容保持一致；同时构建独立课堂两关版本。

Checks cover loop, slopes, jumps, platforms, barriers, rotations/heights. With host GC paused, 1,000 buffered calls measured 0.00 KB Lua growth.

检查覆盖主循环、坡道、跳跃、平台、挡板及不同旋转姿态和高度的遮挡对照。主机暂停 GC 后连续生成 1000 次复用遮挡多边形，测得 Lua 内存增长 0.00 KB。

Hardware sustained inputs ran 450 frames each: worst updates 32.083/28.418/14.442 ms for Courses 13/14/class, near 30 FPS without updates above 33.33 ms. Maximum display intervals were still about 37.6/36.6/34.6 ms. This is not an all-route or long-duration guarantee.

最终真机持续输入测试：第 13 关最慢更新 32.083 ms，第 14 关 28.418 ms，课堂短关 14.442 ms；每场景 450 帧，均约 30 FPS，没有超过 33.33 ms 的游戏更新。实际最大帧间隔仍分别约 37.6、36.6、34.6 ms；不能据此承诺所有关卡、所有路线或长时间运行绝无卡顿。

See [performance](performance-v0.5.7.md) and [reflection](reflections/v0.5.7.md).

详见 [逐轮性能记录](performance-v0.5.7.md) 和 [设计思考](reflections/v0.5.7.md)。

完整版与课堂版均已安装到真机，分别启动后收到运行日志与启动检查通过信息；最后启动的是 Sky Hamster Core Test 0.5.7-core。
