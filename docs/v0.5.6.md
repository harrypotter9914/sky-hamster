# v0.5.6 — 开局输入与移动视角性能修复

- 教学关闭帧同时接受方向和摇柄输入，不需要再次按键；零力度静止时增加顺摇提示。
- 关卡开始前准备坡面遮挡和 HUD 缓存，避免首次游玩时临时生成。
- 屏幕外动态机关跳过绘制，保留边缘余量；物理计时继续正常运行。
- 分块缓存经过真机对照后默认关闭，保留整图静态缓存。
- 减少无机关场景临时空表分配；课堂 HUD 缩短标签避免遮住速度。
- 构建脚本从 pdxinfo 读取版本，继续输出完整 14 关与课堂两关两个独立包。

完整主机回归与 SDK 两配置编译通过。真机对照显示前两关与复杂关平均更新改善，但长关仍有偶发尖峰，尚未完全解决。最后一轮设备连接中断，最终包尚待重新连接后安装与复测。
