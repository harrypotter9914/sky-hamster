# v0.6.2 — 更清楚的玻璃珠滚动音色

根据试听反馈，提高滚动播放器的低速音量和上限：音量曲线由 min(0.65, 0.1 + speed/350) 改为 min(0.85, 0.22 + speed/300)。例如速度 30 时播放器音量由约 0.186 增至 0.32。增加短促的明亮共鸣接触声，补充原先主要在低频的滚动纹理。

声音仍按速度改变节奏与音高，停止和腾空时停止播放。循环长度和采样格式不变，无新增运行时合成。其他音效和背景音乐不变；课堂版仍保持无声音的 0.5.8。

本版包含 0.6.1 的标签层级与选关返回修复。生成脚本检查 PCM 峰值、既有主机回归和 SDK 编译通过。音量与质感还需要实际试听确认。

设备连接已恢复，完整版 0.6.2 已安装并启动，收到启动检查通过日志。课堂包保持 0.5.8。
