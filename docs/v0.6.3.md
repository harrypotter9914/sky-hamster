# v0.6.3 — Rolling contacts without fixed pitch

# v0.6.3 — 无固定音高的滚动接触声

Removed bass oscillation, nine-per-second pulses, and fixed resonances. Three seconds of irregular 5–14 ms noise contacts vary strength/spacing with occasional doubles. Removing DC and smoothing highs aims for fine rattles rather than rhythmic beeps/thuds.

移除上一版滚动采样中的低频振荡、周期性九次每秒的脉冲和固定音高共鸣。改为 3 秒的不规则短噪声接触序列，每次接触约 5–14 毫秒，力度与间隔变化，偶尔出现靠得很近的双接触。去除低频直流成分并平滑高频，目标为细碎“咯啦”而不是低沉或有节奏的“嘟嘟/咚咚”。

Retains 0.6.2 gain/speed mapping, other sounds/music/logic. PCM peak check passes at 0.26 and SDK builds. Hardware listening decides timbre; synthesis is not presented as a real recording.

保留 0.6.2 的播放器音量与速度映射，其他音效、背景音乐和游戏逻辑不变。生成脚本的 PCM 峰值检查通过，滚动峰值为 0.26；SDK 编译通过。具体听感以真机试听为准，不将合成声音当作真实玻璃珠录音。

Full 0.6.3 installed/launched with startup PASS. Class stays 0.5.8.

完整版 0.6.3 已安装到真机并启动，启动检查通过。课堂版保持 0.5.8。
