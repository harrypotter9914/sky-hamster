## 当前不能宣称的内容

1. **不能宣称当前正式包真机全关稳定 30 FPS。** 最近全关硬件记录来自 0.12.3，场景平均 21.37–30.48 FPS；0.12.5 专项检查仍有 100 ms 最慢帧。0.12.8 本轮没有更新硬件数字。
2. **复杂关仍有加载等待。** 第 53 关此前真机加载约 10.9 秒，有动画但不能宣传瞬时进入。应在测试版说明中如实写明，后续继续以硬件数据优化。
3. **没有本次全关手持真人通关证据。** 路线图、脚本与采样能发现断路和运行错误，不能保证首次玩家都理解动作，也不能保证任意握姿的跳跃体验。
4. **旧自由选关存档有兼容例外。** 原当前进度范围与已完成记录保留；第一次下载安装的新玩家按正常解锁规则游玩。测试锁关应明确从 New Game 建立新进度。

这些限制允许以清楚说明的测试版收集反馈，但不支持写成“已经彻底完成且所有设备流畅”。itch.io 允许未完成与早期项目，页面应准确标明状态。[创建者入门](https://itch.io/docs/creators/getting-started)、[质量准则](https://itch.io/docs/creators/quality-guidelines)。

## 页面公开前要准备

- 明确为 **Playdate 游戏**，需要 Playdate 真机；模拟器适合预览，但不能完整代替倾斜手持体验。不要将 `.pdx` 标为 Windows／macOS／Linux 的原生可执行游戏。[准确的平台标识](https://itch.io/docs/creators/quality-guidelines)。
- 独立 itch.io 封面：游戏机器内的 350×155 卡片不能直接当成比例合适的页面封面；建议 630×500，配 3–5 张真实游戏截图和简短玩法说明。[封面及截图建议](https://itch.io/docs/creators/getting-started)。
- 页面写清：倾斜移动、反向倾斜减速、两种操控、校准、A 跳跃备用、摇柄机关、A 炮台发射、B 解除，以及 New Game 会重置什么。隐藏开发快捷方式不放到玩家说明。
- 下载 `sky-hamster-v0.12.8.zip`，通过 Playdate 账号侧载；模拟器使用时先解压 `.pdx`。[Playdate 官方侧载说明](https://help.play.date/games/sideloading/)。
- 将长关加载、复杂场景可能掉帧及测试版状态写进已知问题；安排首次玩家从新存档进入，检查控制选择、完整短关与退出续玩。
- 发布元数据按素材实际情况填写生成内容标签。本项目确有生成图像，不能在平台填写与事实不符的素材声明；不需要为此把开发过程写成玩家说明。[生成内容披露规则](https://itch.io/docs/creators/quality-guidelines)。
- 当前音效为项目合成，历史外部录音不在当前构建；开发模板和语言服务器不随游戏包分发。游戏包中不包含 SDK 二进制，发布与素材使用应遵循实际资源许可。[SDK 许可](https://play.date/dev/sdk-license/)。

上述是核查中尚未完成的页面准备，没有将页面发布操作作为本轮已完成结果。
