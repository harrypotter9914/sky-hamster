# v0.5.3 — 按列选关

Each page puts its first three courses left and next three right: 1/2/3 versus 4/5/6, then 7/8/9 versus 10/11/12; final 13/14 sit left.

每页左列为前三关，右列为后三关。第一页左列 1/2/3、右列 4/5/6；第二页左列 7/8/9、右列 10/11/12；最后一页左列 13/14。

Up/Down follow a column; Left/Right change columns and page at outer edges. Missing cards cannot be selected. A confirm/B return stay.

上下沿当前列移动；左右切换列，在最外侧继续左右可翻页。不存在的卡片不可选。A 确认和 B 返回保持不变。

SDK/Lua 5.4 checks cover ordering, same-row column changes, pages, and final bounds. Gameplay unchanged.

验证：SDK 编译及 Lua 5.4 回归检查，包含列内顺序、同行切列、跨页与最后一页边界。游戏玩法未改变。
