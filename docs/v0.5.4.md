# v0.5.4 — Hardware performance

# v0.5.4 — 真机性能优化

- Cache static tracks on entry rather than redrawing tiles.

- 静态赛道在进入关卡时缓存，避免每帧重画所有地砖。

- Cache static occlusion bounds; draw directly when unobstructed.

- 静态遮挡范围缓存；无遮挡时直接绘制球。

- SDK rasterizes clipped polygons instead of Lua pixel rays/image reads.

- 遮挡改为剪裁后的多边形区域，由 SDK 栅格化，替代逐像素 Lua 射线与图像读取。

- Cache fixed HUD; update time/speed only on change.

- HUD 固定部分缓存，计时与速度文本变化时才重新绘制。

- Reduce redundant trigonometry/temporary objects and collect transition allocations at course changes.

- 减少不必要的三角函数与临时对象，在关卡切换阶段回收过渡分配。

Collision, force, jumping, and content stay. SDK, 14-course logic, and occlusion-equivalence checks passed. Short hardware samples approach 30 FPS, with one Course 13 update of 36.451 ms; no claim of zero drops everywhere.

碰撞、推进、跳跃和关卡内容不变。SDK 编译、14 关逻辑回归和旧新遮挡等价检查通过。真机 14 关短时检查接近 30 FPS；第 13 关仍出现单次 36.451 ms 更新，未声称所有场景绝不掉帧。

See [reflection](reflections/v0.5.4.md) and [performance methods/data](performance-v0.5.4.md).

逐轮发现与改动见 [心路历程](reflections/v0.5.4.md)，测量方法和完整数字见 [性能测试记录](performance-v0.5.4.md)。
