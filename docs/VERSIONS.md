- 原有 v0.1.0 至 v0.6.7 的标签和发布不变。九个控制变体保留其变体编号，不与正式版本号混用。
- 0.7.0 至 0.10.1 的统一标签指向对应原始源码提交；历史提交信息及当时的源码版本字段不改写，避免伪造开发记录。此表明确记录新旧对应关系。
