# v0.5.8 — Edge-fall correction

# v0.5.8 — 边缘掉落修复

Falling continues world position, horizontal velocity, gravity height, and side contacts while the camera stays at the edge. Rendering/occlusion share actual height, replacing a shrinking screen-only downward animation.

滚出边缘后继续更新球的世界坐标、水平速度和重力高度，处理平台侧壁接触；相机保留在离开边缘处。渲染和遮挡使用同一个实际高度，移除原先只沿屏幕向下平移并缩小球的假掉落动画。

Both modes retain automatic retry after 0.8 seconds. Classroom receives the fix first; audio/title iterate separately.

保持 0.8 秒后自动重试，课堂版和完整版一致。修复优先部署到课堂版，后续声音和开始界面另行迭代。

Host checks cover four-edge inertia, height, camera, counts, and retry, including class. Simulator shows outward falls; hardware four-direction checks pass, with logged positions (48,145.88), (-18.88,80), (338.88,176), (48,13.12), all negative heights.

验证：主机四个边缘的惯性、高度、相机、掉落计数及自动重试回归；课堂短关同样通过。模拟器检查球从平台外侧下落；真机四向掉落检查全部通过，日志中的落点分别为 (48,145.88)、(-18.88,80)、(338.88,176)、(48,13.12)，高度均为负数。
