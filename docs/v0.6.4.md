# v0.6.4 — Real marble rolling sample

# v0.6.4 — 真实玻璃珠滚动采样

Broken-glass/noise feedback led to JuandreSound's CC0 tile-floor recording: seconds 0.5–4.6, mono, gentle low/high filtering, and 100 ms overlap produce a four-second loop. Source and repeatable processing script remain.

上一版不规则噪声颗粒被反馈为碎玻璃、杂音，缺少完整玻璃珠清脆圆润的滚动质感。本版改用 JuandreSound 的 CC0 瓷砖滚珠录音，截取 0.5–4.6 秒，转为单声道，温和过滤低频与高频，加入 100 毫秒循环交叠，得到 4 秒滚动采样。来源及可重复处理脚本已保存。

Other audio/music/triggers/gameplay stay; class remains 0.5.8-core.

其他音效、音乐、滚动触发规则与游戏机制不变。课堂安装版本仍为 0.5.8-core。

Verified 22050 Hz/16-bit mono PCM, normalized peak 0.650, seam difference about 0.000020, SDK build. Waveforms cannot replace listening. No USB/serial device was detected, so installation/listening remain incomplete.

验证：22050 Hz / 16-bit 单声道 PCM，归一化峰值 0.650，循环接缝幅度差约 0.000020；SDK 构建通过。处理后的听感仍需试听确认，波形检查不能代替听感判断。本次安装检查未检测到 Playdate USB 设备或串口，尚未安装或完成真机试听。
