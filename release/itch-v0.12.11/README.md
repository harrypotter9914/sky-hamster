# 0.12.11 · 隐藏开发入口与有效快捷菜单

本地发布包：`../../builds/sky-hamster-v0.12.11.zip`。顶层单一 `sky-hamster-tilt.pdx`，完整 53 关，version 0.12.11 / build 61。

新游戏仅从主页 Start Game 进入。设置页保持五项偏好，没有可见开发入口；长按 A+B 约 2.5 秒切换临时开发权限，启用后可从系统菜单自由选关。重启自动关闭，普通玩家按进度解锁。

快捷菜单随界面显示有效动作，选关取消返回打开前的位置。地图提供 Resume game。普通主页和加载不显示游戏自定义快捷项，系统自带菜单仍由 Playdate OS 管理。
