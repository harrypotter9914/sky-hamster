## 玩家操作

1. 标题页进入 Settings。
2. 同时长按 A+B 约 3 秒，直到顶部显示 DEVELOPER，松开两键。
3. B 返回标题，Start Game → Continue（如出现），进入一关；首次启动完成必要的开场选择和校准。
4. 在关卡中按 Playdate Menu → Level select，方向键浏览 53 关，A 进入，B 返回。

0.12.9 的 `openSelector` 在标题和设置中会直接返回，因此步骤明确先进入关卡；不能照搬本地 0.12.11 之后允许从开发模式标题／设置直接选关的行为。源码依据为 `f3f7bb0` 中的 engine.lua、campaign_access.lua 与 tilt_ui.lua。组合键阈值 2.5 秒，面向玩家写约 3 秒。

说明明确这不是独立开发版下载，试玩不覆盖普通通关进度和最佳成绩，也不保存开发模式的新纪录；重启关闭模式，或回 Settings 再长按关闭。逐步学习的正常流程保留。
