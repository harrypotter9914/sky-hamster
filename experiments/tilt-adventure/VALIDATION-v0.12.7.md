# 0.12.7：恢复新试玩入口

来源核对：Mac 会话“安装并验证 Playdate Lua 环境”中，用户明确要求 Settings 添加开始新游戏以便新试玩者重看指引。该会话记录确认当时为未推送的本地修改，后续已安装真机。当前 GitHub main 与 Windows 主线均没有该入口。本轮按原行为补回，并与现有第五项 Steering 合并为六项设置。

## 行为与检查

- A 打开确认页，默认 Cancel；A 取消或 B 返回均不清档。左右键不打开或执行新游戏。
- 明确选择 Start New Game 并按 A 才清空完成进度、最佳成绩、教程标记；第一关重新加载，计时、死亡、检查点、速度、空中状态重置。
- 音效、音乐、场景动画、跳跃手势、SCREEN／ROAD 偏好保留。新存档重载后仍从第一关和初次教学开始，后续跳跃、机关、大炮教学也重新具备出现条件。
- `tests/check_new_game.py` 执行真实菜单更新与存档重载，上述路径通过。
- `tests/check_playtest_controls.py` 通过：160 个握姿／方向案例、同角度推进与反向刹车、设置保存、惯性、重力与时间步检查。0.12.6 手感未改动。
- 原生资源重新导出，53 关道路、3286 个道路精灵及 134 个炮台／风机帧通过 `check_runtime_assets.py`。本轮无地形设计修改，导出过程会重新编号部分缓存图片。
- 模拟器原生渲染六项设置和两个确认选中状态，检查 400×240 画面，文字及底部按键无重叠。复现脚本 `tests/new_game_review.lua`；截图见 `tests/new-game-menu-v0.12.7.png`。

正式 0.12.7／build 57 覆盖原游戏目录，main.pdz 与本地 SHA-256 一致：448d88cf8db7d5f1a362a9fa0818cce0846a65cede22f41f1d8fb6bd82520687。捕获首页 READY，检查六行设置、打开确认页、默认 Cancel 与 B 返回设置，截图见 tests/device-new-game-v0.12.7.png。没有在真实存档上确认清档；清档与重载路径由隔离的真实 Lua 菜单测试验证。
