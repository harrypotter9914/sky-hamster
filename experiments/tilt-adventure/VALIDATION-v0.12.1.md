# 0.12.1：长关加载触发系统保护

## 根因证据

真机 `errorlog.txt` 记录了两次 `Run loop stalled for more than 10 seconds`：2026-09-28 22:11:05 停在 `joinery.lua` 的接岸计算，22:47:28 停在 `spatial.lua` 的地形遮挡准备，经 `prepareTerrain()`、`selectLevel()` 调入。原始日志保存在 `tests/device-error-before-load-fix-v0.12.0.txt`。日志中的 09-26 import 错误属于已修复的历史事件，不是本次新增错误。

因此此前仅按 USB 无响应处理是不充分的：本次确实有运行循环超时崩溃，断连是出现崩溃后的现象。此日志不支持把根因说成存储容量不足或内存溢出。

## 修复

- 按遭遇分批生成长关路线，接岸扫描每 128 格交还加载器，地形遮挡每 32 格交还加载器；各阶段之间返回主循环，让画面和系统继续运行。
- 存档停在长关时，导入游戏只保留轻量关卡配置。首页按 Start 后，才在分帧加载器内生成这张地图。
- 测试工具的场景规划与实际进关同样分帧执行，不在一次回调里排空全部加载。加载阶段不计入玩法 FPS；日志记录单次加载更新的最长耗时。
- 关卡几何、机关美术、碰撞、声音与既有进度迁移保持原有行为；此版是 0.12.0 的修复版。
