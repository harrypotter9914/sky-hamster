# 0.12.10 · 按键教学图

使用内置图片生成工具制作 `shortcuts-original.png` 四格图集；完整提示词在 `prompt.txt`。沿用已有教学页、玻璃仓鼠球和黑白像素风格，分别表现路线地图、教学书、终点路线说明，以及舒适握姿的中立校准。

`../prepare-shortcuts.py` 分割四格、裁掉外侧留白，等比例缩小到 160×94 的固定黑白画布，导出到 `../../source/tutorial-tools/`。正文和按键使用游戏现有字体与对齐规则，避免把生成图片中的字缩成不可读的纹理；不会拉伸插图。

四张图片仅在教学模块初始化时加载、之后复用。按键边框轻微闪动提示可以试按，不实时缩放、生成位图或改变正文位置。跳跃沿用已有生成的设备／球素材，动画前半显示抬机、后半显示 A 备用跳跃，分隔明确的说明行提示炮台中 A 是发射。
