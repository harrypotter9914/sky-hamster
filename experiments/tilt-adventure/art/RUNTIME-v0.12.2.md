# 运行时图片预生成

此流程把现有 SDK 绘制代码的结果提前保存为图片，不重新设计或简化画面。

1. 在 Windows、Playdate SDK 已安装的环境执行 `art/bake-runtime.ps1`。它构建隔离的导出包，启动模拟器，逐关生成原有道路表面，以及大炮和风机的固定角度画面。导出成功时 `Disk/Data/com.wangyibo.skyhamster.bake/bake-report.json` 的 `complete` 为 true。
2. 执行 `python art/collect-runtime.py`。脚本以尺寸和 RGBA 内容去重道路图片，将 GIF 无损转存为 PNG 顺序图集，并输出每关坐标映射。图集由 pdc 编译为 PDT，不会在真机上展开为一千多个图片文件。
3. 执行 `python tests/check_runtime_assets.py`，确认源文件指纹、53 关地块坐标及图片索引。正常构建、性能构建和画面审查均先调用 `art/check-bake.ps1`；修改相关绘制或地图代码后必须重新生成，避免使用过期贴图。
4. 执行原生画面对比；0.12.2 使用已打包图片的 118 张终局／地图／选关画面与 0.12.0 基线逐像素一致。

当前产物为 1647 个去重后的道路表面、62 帧大炮（含底座）、72 帧风机外壳。风扇叶片、气流、机关位移和碰撞继续按实时状态更新。道路图片随后按相机附近的 256 像素区块分批组合；碰撞地图不延迟加载。
