# 0.12.11 · 菜单去重、隐藏开发入口与场景权限

2026-10-09，build 61。53 关、图片和控球手感保持不变。

## 改动与入口

- Settings 移除重复的 Start New Game。普通设置始终只有音效、音乐、场景动画、抬机跳跃和 Steering 五项。主页 Start Game 的 Continue / New Game 及重置确认保留。
- 开发入口完全隐藏，没有新增可见选项：设置页同时长按 A+B 约 2.5 秒切换。开启后显示已有的开发状态，系统菜单允许主页／设置打开 Level select；再长按或重启关闭。测试关卡不改变普通进度、成绩或教学记录。
- 选关页面记录来源，B 还原主页、设置、地图、当前关或结局；选择关卡后关闭父页面，避免加载完仍停在设置。普通玩家仅能进入已解锁关卡。
- 自定义系统快捷项依据当前状态生成，最多三项。普通主页与加载无自定义项；设置提供返回主页；正常游玩提供选关／地图／主页；地图提供 Resume game；帮助和目标说明不显示不可用的选关／地图项；失败和结算仍可选关或返回主页。Playdate OS 自带菜单没有改变。
- 仅在有效动作集合改变时重建菜单，恢复同样的场景不反复分配菜单项；显示判断与执行权限共用，旧回调也拒绝从错误页面跳转。打开 OS 菜单时刷新一次，避免状态刚变化时出现旧项。
