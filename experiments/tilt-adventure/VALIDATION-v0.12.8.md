# 0.12.8：操控对照、开始选择与正常解锁

日期：2026-10-09。保留 0.12.6／0.12.7 手感、53 关布局与所有机关；本轮修改菜单和进度访问规则。正式包版本 0.12.8，build 58。

## 行为

- Settings → Steering 按 A 进入双卡片页。左右只改变当前选中卡片；A 保存方向模式并回设置，B 取消。当前已保存模式另有小圆点。四个倾斜方向同步演示，Screen 显示屏幕方向，Road 显示斜视道路轴；物理和教学继续使用同一个 Tilt.mode。
- 已有进度时，首页 Start Game 进入 Continue / New Game。B 返回首页；New Game 打开原确认页，默认 Cancel，取消返回来源菜单。第一次游玩直接从第一关开始。
- 新存档最初只开放第一关；通关开放下一关，完成关可重玩。锁住路线显示生成的锁图标、LOCKED 和前置通关提示，按 A 不改变关卡或当前游玩状态。
- 兼容旧版自由选关存档：以前保存的当前关及其之前的进度范围、已完成记录不收回。要检查从零开始的锁关体验，应从 New Game 建立新进度；安装更新不会清档。
- 设置页同时按住 A+B 约 2.5 秒切换临时开发模式。不在玩家操作提示中展示快捷方式；长按只触发一次。开发模式可选全关，但不写入通关、最佳成绩、测试教程或跳关位置；模式不持久化。关闭时恢复正常关卡与教程，新游戏也关闭模式。

- 新游戏先显示 arrival 目标介绍，再进入操控对照，默认 Road。A 确认保存后显示随时在 Settings → Steering 更改的提示，再继续 roll 教学；B 返回目标介绍，不能跳过选择。选择过程球和计时暂停，确认键不会误触发跳跃。
- 新存档默认 Road，旧版有效偏好继续保留；新游戏重新选操控。未完成选择便退出，继续时恢复选择；完成后重启保留模式，不重复强制选择。设置中的确认同样保存，取消不改变模式。

## 验证

18 个主机脚本通过，完整结果见 [RELEASE-CHECKS-v0.12.8.json](tests/RELEASE-CHECKS-v0.12.8.json)。其中 14 个使用当前 53 关，另外 4 个显式使用历史几何夹具检查机关、音效、提示与唤醒，不将这些旧夹具称为最新全关验证。

- 新菜单真实事件覆盖确认／取消、暂停物理、存档、旧进度迁移、锁关拒绝、通关解锁、一次性隐藏长按、开发成绩及教程隔离。
- 真实 main 启动、基础教学、地图／帮助／目标、失败重试、检查点、通关／下一关、结尾／首页，以及存档重载继续流程通过。部分触发测试直接摆放球位置；不等于真人全通关。
- 当前 53 关的终点和检查点拓扑可达；四个终局脚本路线通过。部分连续脚本会设定位置和速度，另有两种方向模式的起步、刹车弯、折返和炮台真实倾斜输入测试；不据此保证所有玩家都能顺利通关。
- 原生资源重新导出：53 关道路、3286 个表面、134 个大炮／风机角度帧通过源码指纹、坐标和索引检查。导出过程中部分表面编号变化，地图与画面内容没有主动改变。
- 45 个 WAV 文件非空、均为 22050 Hz／16 bit／单声道，内容哈希互异。事件、暂停、音量衰减与声部限制回归通过；本轮未逐一在真机上人耳试听。

模拟器完成全 53 关、203 个采样场景，无记录到的运行错误，原始结果见 [SIMULATOR-v0.12.8.json](tests/SIMULATOR-v0.12.8.json)。这是程序控制采样位置和机关状态的检查，不是逐关人手游玩。原始 device 标志由 getStats 是否存在决定，模拟器也可能为 true，不能据此称为真机数据。全关采样之后修改了新游戏的操控选择衔接、保存标记和菜单图片排版；关卡、物理与世界渲染没有改变。最终引擎的完整 main 游玩循环、新手选择中断重载与下述原生菜单帧另行复测。

cacheMiss 是每关累计的即时补图计数，测试跨位置跳转会触发；Terrain.draw 在同帧完成缺少的可见图片，不把缓存是否存在当作碰撞支撑。连续 240 单位／秒往返与检查点跳转专项测试通过：移动过程没有抢到未完成道路，跳转触发完整补图。采样计数不能写成零，也不能当成玩家看见地面缺口。

原生画面检查：此前 0.12.7 的 99 帧基础界面／教学／代表关卡检查，本轮再导出最终菜单 298 帧（58 个状态／姿态样本和 240 帧完整对照动画）。检查两种选中状态、四向动作、Continue／New Game、确认页、锁关／已完成／开发选关，保存提醒最后一行贴近底线，调整间距并移除无作用的 B 图标后再次导出；最终未见新增文字覆盖边框或按键缺失。截图见 [release-menu-v0.12.8.png](tests/release-menu-v0.12.8.png)，动画见 [steering-v0.12.8.gif](tests/steering-v0.12.8.gif)。

检查发现并处理：用户指出 Continue／New Game 框来自竖卡片压扁，重新生成独立横版按钮母版，等比例导出，取消该拉伸路径。新手流程加入默认 Road 的选择和保存提醒，并检查中断重启不会跳过。初版卡片遮住上方说明，底部标签碰边，球体缩小后玻璃轮廓不清；移开说明、留出边距、增强选中标题、改成 24×24 球体并仅透明化轮廓外的背景。旧输入测试仍期待一步切换模式和一步开始加载，按新的确认流程修正，保留存档及调度断言。没有因此改变加速度、刹车、机关或道路。

## 真机与发布限制

按本轮要求没有连接、安装或重新测真机。最近全 53 关真机记录是 0.12.3 的 203 场景采样，场景平均帧率 21.37–30.48，最慢帧 95 ms；0.12.5 的 7 关专项记录为 22.24–30.29，最慢帧 100 ms，第 53 关加载 10.894 秒。本轮模拟器不能更新这些硬件结论，也不能代替新菜单在手持状态下的易用性检查。

建议当前作为公开测试版，而非宣称稳定 30 FPS 的最终完成版。发布前页面材料、安装与设备说明、已知限制仍需完整准备，见 [发布核查](../../docs/RELEASE-READINESS-v0.12.8.md)。
