# 九个控球规则比较原型

## 新增 06–09

原先 01–05 均保留，九个独立安装包在同一个 `builds/variants` 文件夹。

| 编号 / 文件后缀 | 新规则 |
| --- | --- |
| 06 reverse | 顺摇累积正向推力，逆摇累积负向推力；负向推力可以先减速再倒退。停止摇动后推力衰减。方向键选择作用轴。 |
| 07 track | 专用断桥关：先停在 CONTROL 标牌下的控制点（世界坐标 80,80，半径 22，速度低于 15），按住 A 转动摇柄控制桥梁角度。桥不会自动转；放开 A 后用顺摇推进、方向键控制球过桥。转约 90 度连接左右平台；B 重试重置桥。 |
| 08 lock | 有推力时锁定整个推进方向，包括小转弯；松摇等待推进条衰减为零后才能换方向。球保留惯性。 |
| 09 absolute | 摇柄绝对位置决定屏幕上的推力方向（0 度向上，90 度向右）；按住 A 持续加速，松开停止推力并保留惯性。改变摇柄位置不会瞬间改变已有速度，需要推力逐渐转弯。 |

09 与 04 的区别：04 累计转角，每次重试朝向重置；09 直接读取摇柄绝对位置，重试也保持位置映射。两版都保留松手惯性。
07 的轨道操作需要专用关，不能把它的通关时间直接与其他八版的短赛道比较；应比较停车、路线规划和控球体验。
新增自动测试 `tests/check_extra_variants.py` 覆盖反向运动、方向锁定、绝对朝向和松手惯性，以及手动桥连接后通过真实 update 通关与重试。

基于 Sky Hamster v0.6.7 与已有心路历程重新制作。不是旧版原件，也不是已经通过玩家测试的结论。当前完整版的默认玩法保持不变。

## 五个版本

| 文件后缀 | 规则 | 来源与这次要问的问题 |
| --- | --- | --- |
| speed | 顺摇提高目标速度，逆摇降低；方向键把速度逐渐调整到目标向量。松开方向键缓慢滑行。此版不施加坡道重力。 | v0.1 的速度设定方向。这种容易理解的控制是否牺牲坡道与动量体验？不是逐字还原旧代码。 |
| throttle | 摇柄调持续推力，停摇保持；逆摇降低油门；反向方向键额外刹车。零推力仍受重力影响。 | v0.2 的持续油门。玩家会不会开局摇满后不再使用摇柄？ |
| brake | 顺摇补充推力，停摇衰减；逆摇清除当前推力并主动刹车，不产生反向速度；没有反向清条卡扣。 | v0.3 记录中放弃的“逆摇刹车”。刹车是降低挫败还是消除挑战？ |
| steering | 摇柄转动推力方向，按住 A 推进，松开滑行；方向键不参与运动。每次重试初始朝世界 +X，HUD 箭头按赛道斜视投影显示。 | v0.1 记录中的“摇柄方向控制”，A 推进是本次新增的具体实现选择。方向映射和双手分工是否自然？ |
| latch | 顺摇补充推力，停摇衰减；高力度大幅反向清空推进条；没有额外刹车，逆摇不使用。 | 当前核心规则作为对照。清条是否促成提前规划，还是令玩家困惑？ |

五版共享相同平地短赛道和可选坡道、碰撞、掉落重试、画面和计时；跳跃、机关、声音关闭。目标速度版的重力差异是规则差异的一部分。各版打包为独立名称与 bundleID，可同时安装。B 重试；菜单可选关、看地图和重新开始。

## 在 Mac 上构建运行

在项目根目录运行 `bash build-variants.sh`，生成 `builds/variants/sky-hamster-*.pdx`。
脚本在临时目录组装源码，不改写默认 `source/build.lua`。只打包 Lua 文件，音频关闭时不需要音频资产。

VS Code：命令面板 → Tasks: Run Task → Run a variant → 选择规则。
原来的 Cmd+Shift+B / F5 仍面向完整版。也可直接用 Playdate Simulator 打开各个 .pdx。
模拟器默认键位：S 对应 A，A 对应 B，方向键控制方向；可取消 Docked 后拖动模拟摇柄。
实机连接解锁后，在模拟器选择 Device → Upload Game to Device。

## 对比试玩

先用同一平地关，给各版本相同的试玩时间，并轮换版本顺序，减少先玩后玩带来的学习影响。坡道作为第二轮，不混入第一轮比较。

测试前由设计者填写每版预测；测试中记录玩家操作和原话；测试后再写原因诊断。不要把下面的问题写成已发生的结果。

| 玩家 / 版本 / 顺序 | 事前预测 | 实际操作及掉落 | 玩家原话 | 诊断 | 保留或修改 |
| --- | --- | --- | --- | --- | --- |
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

重点看：能否说明摇柄控制什么、接近弯道是否主动松手、如何挽救失误、第二次是否改变策略，以及是否还愿意再试。

## 验证

五版均通过 SDK 3.1.1 编译。`tests/check_variants.py` 使用 Lua 5.4 检查规则差异及真实 update 流程、重试和选关；原有 `tests/run_checks.py` 检查完整版回归。运行 Python 测试需安装 lupa。
模拟器检查不等于五版实机验证或真实玩家测试，后两项仍待完成。
