# Showcase media provenance

[Project home](../README.md)

- `film-cover.png`: existing official film cover, with the approved Sky Hamster Logo and promotional illustration. It is artwork, not a gameplay frame.
- `jump.gif`, `turntable.gif`, `cannon.gif`: v0.12.9 Simulator previews from `release/itch-v0.12.9/`, driven by scripted input in an isolated save. The depicted mechanics remain in v0.12.12.
- GIFs are enlarged from 400×240 to 800×480 using nearest-neighbor scaling. All original animation frame durations are retained; no interpolation, generated gameplay, or invented input overlays were added.

The public English design film is [here](https://www.youtube.com/watch?v=iNOELVQz9kg). Hardware verification is documented separately in [release evidence](../docs/RELEASE.md).
